# Submission bundle

`tables/Supplementary_Tables_S1-S12.xlsx` is the supplementary workbook: a `Legends` sheet, an `index` sheet and one sheet per table, each sheet holding its parts one after another with the column definitions in row 2. `supplementary_table_index.csv` lists every part and the file it comes from; `table_and_figure_provenance.csv` in the repository root adds the script that writes each one. `manuscript_number_agreement.csv` is the machine comparison of every number in the manuscript against the bundle, `manuscript_unmatched_numbers.csv` the ones it cannot place and where they live instead. `figures/pptx/` holds one editable slide per figure, built from the text-free renderings and the position metadata. `checks/check_worksheet_final.xlsx` is the record of the cell-by-cell check.
